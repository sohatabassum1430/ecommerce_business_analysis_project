🛒 Ecommerce Business Analysis
A full end-to-end data analysis project covering SQL Server, Python, and Power BI. Raw data is cleaned and transformed in SQL, analysed in Python, and visualised in a Power BI dashboard.

📌 Project Overview
Tool	Purpose
SQL Server	Database creation, data cleaning, business KPIs
Python	Data loading, feature engineering, charts
Power BI	Interactive dashboard and DAX measures
